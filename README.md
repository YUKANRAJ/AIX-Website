# AIX - AI Innovation eXchange

Official website of **AIX (AI Innovation eXchange)**, a student-driven AI community focused on artificial intelligence, innovation, research, collaboration, and hands-on learning.

## 🌐 About AIX

AIX is an AI-focused student ecosystem that brings together students, faculty, researchers, and industry professionals to learn, collaborate, experiment, and build innovative solutions.

> **Where Curiosity Becomes Innovation.**

## ✨ Features

- 🏠 Modern AIX landing page
- 🤖 AI-inspired interactive background
- 📅 Events and event registration
- 👥 Faculty coordinators and student leadership
- 📱 Responsive design for mobile, tablet, and desktop
- ⚡ Smooth page transitions and animations
- 🧭 Multi-page navigation
- 📞 Contact section
- 🎨 AIX-themed dark technology interface
